# I18N — Internacionalización

Sistema de traducción basado en **keys**, sin textos hardcodeados en componentes.

## Idiomas
- **Español (`es`)** — idioma inicial por defecto.
- **English (`en`)**.

## Implementación
- Context provider: `src/theme/i18n.tsx` (`LanguageProvider`, hook `useLanguage()`).
- Traducciones: objeto anidado en `i18n.tsx` (claves tipo `dashboard.title`).
- Persistencia: `localStorage['bible-shorts-language']`. Al cambiar, se actualiza
  `document.documentElement.lang` y `data-lang`.
- Helper: `t('key', 'default')` resuelve notación punto y cae back al default o a la key.

## Convención de keys
```
dashboard.title
dashboard.videosToday
dashboard.dailyTarget
content.title
content.generate
content.topic
review.title
review.approve
review.reject
calendar.title
settings.title
notifications.title
```

## Agregar un idioma
1. Añadir el objeto `xx` al mapa de traducciones en `i18n.tsx`.
2. Agregar la opción en `src/app/settings/page.tsx`.
3. Listo — no requiere cambios en componentes.

## Regla
Nunca colocar strings literales visibles al usuario directamente en JSX.
Usar siempre `t('namespace.key')`.
